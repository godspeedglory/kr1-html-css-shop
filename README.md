# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- Flexbox для расположения элементов шапки и навигации;
- CSS Grid для расположения карточек товаров;
- базовое БЭМ-именование классов;
- структурированный файл `css/style.css`.

## Flexbox и CSS Grid

Для расположения элементов шапки сайта используется Flexbox.

```css
.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

Навигационное меню также расположено с помощью Flexbox:

```css
.site-nav__list {
  display: flex;
  gap: var(--space-md);
}
```

Для расположения карточек товаров используется CSS Grid:

```css
.product-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-md);
}
```

Карточки товаров располагаются в три колонки.

## БЭМ-именование

Для карточек товаров используется базовое БЭМ-именование классов.

Основной блок:

```text
product-card
```

Элементы блока:

```text
product-card__title
product-card__description
product-card__price
product-card__button
```

Например:

```html
<article class="product-card">
  <h3 class="product-card__title">Товар 1</h3>
  <p class="product-card__description">Краткое описание учебного товара.</p>
  <p class="product-card__price">Цена: 1000 руб.</p>
  <button class="button product-card__button">Заказать</button>
</article>
```
